# 设计决策

先选机型，纵向排列可视角与频闪，共用对比手机。去掉主页面三个标签页。

沿用原网页可视化：原 WebGL 手机画面及圆形方向图、原彩色热力图和立体、原同灰阶二维曲线。方向图与灰阶控件直接保留原版事件处理，不再创建另一套控制逻辑。

暗色、少文字；说明点击打开。频闪固定 ≤500 nits，调光和防窥状态用按钮。水印使用共享稀疏文字底纹，覆盖页面与可视角背景；频闪在画布外围保留水印带，方便截图分享且不改变数据图颜色。

双机可视角分别显示标明机型与防窥状态的原方向图，观看角度联动。大屏两图并排在右侧，较窄屏幕移到手机画面下方，手机端纵排。二维曲线默认 G255。

手机端可视角先画面后方向图；双机热力图纵排，二维曲线同图对比。来源、校验和许可保留在项目文件，不占据主界面。
