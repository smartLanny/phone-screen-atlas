# 验证记录

2026-10-08，纵向布局及六方向数据版本。

## 数据与源码

- 24 个原始 `.ang2` 文件按 SHA-256 校验，共 25,560 个 XYZ 值与源文件一致；四组配置各含六个实测方向，模型均为 12 条真实方向线。
- 原项目 web 与 scene3d 使用同一份数据快照，本站同步该快照；文件名方向优先，修正源文件内部遗留方向标签，保留原归一化和渲染算法。
- `npm run check` 通过：脚本语法、光学样本、LUT、SVM 数据复算、原始矩阵审阅、原版嵌入逐字复现、桥接与本地资源检查。
- SVM 16 条数据共 6696 格，原版渲染和计算未改；固定 500 nits，父窗口／同源检查、文件白名单、换组返回、原灰阶变更通知与 iframe 临时存储均通过检查。

## 实际浏览器

- 可视角在上、频闪在下，无主页面三标签。
- 原圆形方向图亮度／色偏切换、拖动与分享状态同步；双机各自方向图显示对应数据、机型和防窥状态，拖动第二张会同步共同角度。
- 原二维曲线两机同灰阶叠加；默认显示 G255；指定灰阶的分享链接与原快捷按钮仍可切换。
- 390px 手机端无横向溢出，方向图及原灰阶控件完整显示。
- 防窥状态使用按钮；普通状态为“默认”。说明点击打开，主界面无外部引用链接。
- 共享稀疏背景水印位于页面及透明手机画布下方，频闪只在画布外围保留水印带，不覆盖手机、色块与曲线。
